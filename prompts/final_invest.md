# Daily Investment Briefing (v3)

오늘의 투자 전략 브리핑을 작성해서 Slack `#daily-news` 에 전송해줘.
AI 트렌드는 별도 작업이 담당하므로 이 작업에서는 다루지 않는다.

## 0. 공통 실행 규칙 (모든 섹션에 우선 적용)

### 0-1. 날짜
- 시작하자마자 `TZ=Asia/Seoul date` 로 현재 KST 시각을 확정하고, 첫 메시지 최상단에
  `📅 YYYY-MM-DD (요일) HH:MM KST 기준` 을 표기한다.
- 검색어에는 "오늘/today" 대신 실제 날짜 문자열을 넣는다. (예: `AI news October 28 2026`)

### 0-2. 데이터 수집 순서 (중요)
1. **수집 데이터 파일을 먼저 읽는다.**
   `curl -s https://raw.githubusercontent.com/mingunpark/new_briefing/main/data/latest.json`
   - 파일을 못 읽거나(404 등) `generated_at_utc` 가 지금보다 **12시간 이상 오래됐으면** 파일 전체를 쓰지 말고 2단계로 간다.
   - `failed_sources` 에 있는 항목만 2단계로 직접 수집한다.
   - 파일 값은 `[확인됨]` 으로 쓰되, 출처는 파일 안의 `source` 와 `as_of`/`record_date` 를 그대로 옮긴다.
2. **직접 API 호출** (curl). 허용된 도메인: api.fiscaldata.treasury.gov, fred.stlouisfed.org,
   home.treasury.gov, huggingface.co, hn.algolia.com, query1.finance.yahoo.com, api.github.com
3. 그래도 실패하면 WebFetch / WebSearch 로 1차 출처를 찾는다.
4. 모두 실패하면 `❌ 확인 실패 (시도한 출처: …, 사유: …)` 로 남긴다.

**금지**: 출처 없는 값을 `~`, `약`, `추정` 같은 근사치로 채우기. 숫자는 출처가 있는 값만 쓴다.
(예외: 원화 환산·용량처럼 출처 값으로 직접 계산한 값은 `≈` 로 표기할 수 있다)
네트워크 오류가 나면 같은 URL을 반복하지 말고 다음 단계로 넘어간다.

### 0-3. 사실 검증
- 모든 수치·사실에 ① 출처 ② 기준 시각을 붙인다. 예: `10Y 4.99% (US Treasury Par Yield, 10-27)`
- 핵심 수치는 서로 다른 2개 출처로 교차검증한다. 다르면 둘 다 적고 `⚠️ 출처 불일치` 표기.
- 신뢰도 라벨: `[확인됨]` / `[아마도]` / `[미검증]`
- 항목 수를 채우려고 오래된 뉴스나 유명 프로젝트로 빈칸을 메우지 않는다. 부족하면 "오늘은 N건"이라고 밝힌다.

### 0-4. 중복 방지 (Slack 기록 기반)
- 로컬 파일은 실행 사이에 남지 않으므로 사용하지 않는다.
- 작성 전에 Slack `#daily-news`(채널 ID `C0AVBCP4QK0`)의 **최근 7일 메시지**를 읽어
  이미 다룬 키워드·레포·모델·뉴스를 목록으로 만든다.
- 이미 다룬 항목은 제외한다. 단, 중대한 후속 전개가 있으면 `🔄 후속` 태그로 재등장을 허용한다.

### 0-5. Slack 전송
- 채널: `#daily-news` (`C0AVBCP4QK0`), Slack 커넥터의 메시지 전송 도구를 사용한다.
- mrkdwn 문법: 굵게 `*텍스트*`, 링크 `<https://url|텍스트>`. `**`, `#` 헤더, 표는 쓰지 않는다.
- 메시지 1개는 3,000자 이내로 나눠 보낸다. 전송 실패 시 1회 재시도하고, 그래도 실패하면 에러를 출력한다.

### 0-6. 가독성 (강제)
- 첫 메시지 맨 위에 `⚡ 오늘의 3줄`. 이것만 읽어도 흐름이 잡혀야 한다.
- 각 항목은 첫 줄 = 결론, 그 아래 = 근거 (역피라미드).
- 한 문장 60자 이내, 한 문단 3줄 이내, 한 항목 8줄 이내, 불릿 1개는 1줄.
- 늘어지는 어미(`~라고 할 수 있다`, `~인 것으로 보인다`) 대신 `~다`로 끊는다.
- 구조용 이모지만 쓰고, 문단당 1개 이하. 구분선은 `━━━━━━━━━━━━━━━` 로 통일한다.
- 전문용어는 첫 등장 1회만 괄호로 풀어 쓴다. 근거 없는 수식어(혁신적, 게임체인저, 주목받는)는 금지.
- 항목 사이에는 빈 줄 1개를 넣는다.

### 0-7. 휴장일·주말
- 미 증시나 국내 증시가 휴장이면 "직전 거래일 마감 기준"을 명시하고, 숫자 나열 대신 그 사이 뉴스·선물 동향 중심으로 쓴다.
- 월요일 브리핑은 금요일 마감 + 주말 뉴스를 함께 다룬다.
- `as_of` 날짜가 어제 거래일과 다르면 그 사실을 숫자 옆에 표기한다.

## 1. 데이터 매핑 (latest.json → 브리핑)

| 지표 | 1순위 (파일) | 교차검증 / 폴백 |
|---|---|---|
| S&P500, NASDAQ, DJIA | `market.yahoo.SP500` 등 | `market.stooq_crosscheck` |
| KOSPI, KOSDAQ | `market.yahoo.KOSPI`, `KOSDAQ` | WebSearch 국내 기사 1건 |
| DXY | `market.yahoo.DXY` | WebSearch |
| 원/달러 | `market.yahoo.USDKRW` (글로벌 호가) | `stooq_crosscheck.USDKRW`, 서울 외환시장 종가 기사 |
| 10Y 금리 | `rates.treasury_par_yield` (최신 거래일) | `rates.fred_dgs10` (1영업일 늦음), `market.yahoo.US10Y_YAHOO` |
| TGA | `tga` (`balance_busd`, `wow_change_busd`, `record_date`) | fiscaldata API 직접 호출 |
| VIX, WTI, 금, BTC | `market.yahoo` | 필요할 때만 |

- 원/달러는 **서울 종가인지 글로벌 호가인지** 반드시 구분해서 쓴다.
- 10Y는 어느 출처의 값인지 명시하고, 전일 대비 bp 변화를 쓴다.
- TGA를 fiscaldata API에서 직접 읽을 때 주의: `Treasury General Account (TGA) Closing Balance` 행의 값은
  `close_today_bal` 이 아니라 **`open_today_bal`** 에 들어 있다 (단위: 백만 달러).
- 외국인·기관 수급, 주도 섹터, 이벤트 일정은 파일에 없으므로 WebSearch로 찾는다.

## PART 3. 💰 투자 전략 브리핑

### 작성 원칙
- 숫자 나열보다 "왜 그렇게 됐는지" 원인과 흐름 중심으로 쓴다.
- 주식 비전문가도 이해할 수 있게 쓴다. 숫자가 나오면 "이게 왜 중요한지"를 붙인다.

### [📊 수치 스냅샷] — 코드블록으로 정렬 (아래 숫자는 형식 예시일 뿐 실제 값이 아니다)
```
지표            값         전일비      기준
S&P500       6,120.4      ▲ 0.42%    10-27
NASDAQ      20,315.8      ▼ 0.18%    10-27
KOSPI        2,915.3      ▲ 1.02%    10-27
DXY             98.32     ▲ 0.21     10-27
원/달러       1,382.5      ▲ 4.0원    10-27 글로벌호가
10Y              4.21%    ▲ 3bp      10-27 Treasury
TGA          $712.4B      ▼ $18.3B   10-23 (주간)
```
- 등락은 ▲/▼/– 로 통일한다. 지수와 환율은 소수점 1자리, 금리는 2자리.
- 큰 달러 금액은 당일 원/달러로 환산해 병기한다. 예: 원/달러 1,380원이면 `$712.4B (≈983조원)`
- 코드블록 아래에 각 지표의 "의미" 한 줄씩. 숫자는 다시 나열하지 않는다.
- TGA 해석: 증가 = 재무부가 현금 흡수 → 유동성 감소 → 위험자산 부담 / 감소 = 반대.
- 10Y 해석: 상승 = 할인율 상승 → 성장주 부담, 은행 예대마진에는 우호.

### [🌍 글로벌 매크로 — 오늘의 핵심 원인] 2~3개
```
*① {사건 이름}*
  → 무슨 일: {한 줄} ({출처}, {발생 시각})
  → 왜 반응: {한 줄}
  → 우리에게: 국내 {}, 미국 {}, 달러 {}
```
인과가 불확실하면 `(해석)` 으로 표기하고 단정하지 않는다.

### [🧭 오늘의 투자 판단 가이드]
국내 주식 / 미국 주식 / 달러 각각:
1. 분위기 한줄 (리스크온 / 리스크오프 / 혼조)
2. 주목할 섹터·포인트 + 이유
3. 비중 조절 시 고려할 점 (초보자 기준)

### [📅 오늘/내일 예정 이벤트]
경제지표 발표, 연준 인사 발언, 주요 기업 실적 (KST 시각 표기). 각각 왜 중요한지 한 줄.

### [⚡ 오늘의 한줄 투자 스탠스]
예: "연준 발언으로 금리 인하 기대 후퇴 → 달러 강세 / 성장주 단기 부담"

마지막에 반드시:
`※ 본 내용은 투자 참고용 정보이며, 최종 판단과 책임은 본인에게 있습니다.`
