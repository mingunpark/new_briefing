### 0-7. 휴장일·주말
- 미 증시나 국내 증시가 휴장이면 "직전 거래일 마감 기준"을 명시하고, 숫자 나열 대신 그 사이 뉴스·선물 동향 중심으로 쓴다.
- 월요일 브리핑은 금요일 마감 + 주말 뉴스를 함께 다룬다.
- `as_of` 날짜가 어제 거래일과 다르면 그 사실을 숫자 옆에 표기한다.

## 1. 데이터 매핑 (latest.json → 브리핑)

| 지표 | 1순위 (파일) | 교차검증 / 폴백 |
|---|---|---|
| S&P500, NASDAQ, DJIA | `market.yahoo.SP500` 등 | `market.stooq_crosscheck` |
| KOSPI, KOSDAQ | `market.yahoo.KOSPI`, `KOSDAQ` | WebSearch 국내 기사 1건 |
| DXY | `market.yahoo.DXY` | WebSearch |
| 원/달러 | `market.yahoo.USDKRW` (글로벌 호가) | `stooq_crosscheck.USDKRW`, 서울 외환시장 종가 기사 |
| 10Y 금리 | `rates.treasury_par_yield` (최신 거래일) | `rates.fred_dgs10` (1영업일 늦음), `market.yahoo.US10Y_YAHOO` |
| TGA | `tga` (`balance_busd`, `wow_change_busd`, `record_date`) | fiscaldata API 직접 호출 |
| VIX, WTI, 금, BTC | `market.yahoo` | 필요할 때만 |

- 원/달러는 **서울 종가인지 글로벌 호가인지** 반드시 구분해서 쓴다.
- 10Y는 어느 출처의 값인지 명시하고, 전일 대비 bp 변화를 쓴다.
- TGA를 fiscaldata API에서 직접 읽을 때 주의: `Treasury General Account (TGA) Closing Balance` 행의 값은
  `close_today_bal` 이 아니라 **`open_today_bal`** 에 들어 있다 (단위: 백만 달러).
- 외국인·기관 수급, 주도 섹터, 이벤트 일정은 파일에 없으므로 WebSearch로 찾는다.

## PART 3. 💰 투자 전략 브리핑

### 작성 원칙
- 숫자 나열보다 "왜 그렇게 됐는지" 원인과 흐름 중심으로 쓴다.
- 주식 비전문가도 이해할 수 있게 쓴다. 숫자가 나오면 "이게 왜 중요한지"를 붙인다.

### [📊 수치 스냅샷] — 코드블록으로 정렬 (아래 숫자는 형식 예시일 뿐 실제 값이 아니다)
```
지표            값         전일비      기준
S&P500       6,120.4      ▲ 0.42%    10-27
NASDAQ      20,315.8      ▼ 0.18%    10-27
KOSPI        2,915.3      ▲ 1.02%    10-27
DXY             98.32     ▲ 0.21     10-27
원/달러       1,382.5      ▲ 4.0원    10-27 글로벌호가
10Y              4.21%    ▲ 3bp      10-27 Treasury
TGA          $712.4B      ▼ $18.3B   10-23 (주간)
```
- 등락은 ▲/▼/– 로 통일한다. 지수와 환율은 소수점 1자리, 금리는 2자리.
- 큰 달러 금액은 당일 원/달러로 환산해 병기한다. 예: 원/달러 1,380원이면 `$712.4B (≈983조원)`
- 코드블록 아래에 각 지표의 "의미" 한 줄씩. 숫자는 다시 나열하지 않는다.
- TGA 해석: 증가 = 재무부가 현금 흡수 → 유동성 감소 → 위험자산 부담 / 감소 = 반대.
- 10Y 해석: 상승 = 할인율 상승 → 성장주 부담, 은행 예대마진에는 우호.

### [🌍 글로벌 매크로 — 오늘의 핵심 원인] 2~3개
```
*① {사건 이름}*
  → 무슨 일: {한 줄} ({출처}, {발생 시각})
  → 왜 반응: {한 줄}
  → 우리에게: 국내 {}, 미국 {}, 달러 {}
```
인과가 불확실하면 `(해석)` 으로 표기하고 단정하지 않는다.

### [🧭 오늘의 투자 판단 가이드]
국내 주식 / 미국 주식 / 달러 각각:
1. 분위기 한줄 (리스크온 / 리스크오프 / 혼조)
2. 주목할 섹터·포인트 + 이유
3. 비중 조절 시 고려할 점 (초보자 기준)

### [📅 오늘/내일 예정 이벤트]
경제지표 발표, 연준 인사 발언, 주요 기업 실적 (KST 시각 표기). 각각 왜 중요한지 한 줄.

### [⚡ 오늘의 한줄 투자 스탠스]
예: "연준 발언으로 금리 인하 기대 후퇴 → 달러 강세 / 성장주 단기 부담"

마지막에 반드시:
`※ 본 내용은 투자 참고용 정보이며, 최종 판단과 책임은 본인에게 있습니다.`

## 2. 전송 순서
메시지 1: `📅 날짜` + `⚡ 오늘의 3줄` (시장 / 매크로 / 스탠스 각 1줄) + 수치 스냅샷
메시지 2: 매크로 + 판단 가이드 + 이벤트 + 스탠스 + 면책 문구
마지막 줄: `_데이터: new_briefing latest.json (생성 {generated_at_kst}) · 실패 소스: {failed_sources 또는 없음}_`

## 3. 전송 직전 체크리스트
- [ ] TGA(`record_date` 포함)와 10Y가 둘 다 있는가
- [ ] 핵심 수치를 2개 출처로 교차확인했는가 (불일치는 ⚠️ 표기)
- [ ] 추정치(~, 약, 추정)가 하나도 없는가. 없는 값은 ❌ 확인 실패로 남겼는가
- [ ] 원/달러 기준(서울 종가 / 글로벌 호가)을 표기했는가
- [ ] 수치 스냅샷이 코드블록 정렬이고 ▲▼ 표기·소수점이 통일됐는가
- [ ] 최근 7일 Slack 기록과 같은 문장을 반복하지 않았는가
- [ ] 면책 문구가 들어갔는가
